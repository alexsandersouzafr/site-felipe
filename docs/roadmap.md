# Roadmap

1. Foundation: tooling, documentation, base UI, and internationalization.
2. Data: Supabase migrations, Storage, RLS, and administrative authentication.
3. Panel: content, media, publication, and translation CRUD.
4. Public website: Home, News, Bio, Schedule, Videos, Photos, and Contact.
5. Delivery: testing, accessibility, observability, and Vercel deployment.

Each phase advances only when its types, lint, applicable tests, and build are green.
