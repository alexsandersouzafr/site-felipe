# 04 — Media and video slice

**What to build:** A data path that lets the conductor securely upload public photo assets and manage accessible photo and YouTube-video metadata for public galleries.

**Blocked by:** 01 — Content foundation.

**Status:** ready-for-agent

- [ ] The administrator can upload media while anonymous users cannot write to Storage.
- [ ] Published photo metadata provides alternative text, credit, collection, and display order.
- [ ] Published video metadata stores a YouTube URL or ID rather than a hosted video file.
