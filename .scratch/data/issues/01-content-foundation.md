# 01 — Content foundation

**What to build:** A versioned Supabase content foundation that lets public reads distinguish drafts, scheduled records, and published records while keeping administrative writes protected.

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] Portuguese is required and English/Spanish fields are optional for localized records.
- [x] A record becomes publicly readable only when its state and publication time allow it.
- [x] Only the authenticated administrator can manage editorial records.
